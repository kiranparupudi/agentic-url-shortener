# URL Shortener API

_Generated by the agentic orchestrator's DocumentationAgent for template set `ambiguous`._

## Architecture

Zero-runtime-dependency service on JDK com.sun.net.httpserver; in-memory ConcurrentHashMap store behind a UrlStore interface (swappable for a real DB later); Base62-encoded auto-increment codes for generated links; fixed-window per-IP rate limiter on the create endpoint; regex + URI-scheme validation on all input.

## Endpoints

### `POST /api/shorten`

Request body:
```json
{
  "longUrl": "https://example.com/some/page",
  "ttlSeconds": 3600
}
```
`ttlSeconds` is optional; omit it for a link that never expires.

### `GET /{code}`

302 redirect to the original URL, or `404` if unknown/expired.

### `GET /api/analytics/{code}`

Returns click count, createdAt and lastAccessedAt.

### `GET /health`

Liveness probe, always `200 {"status":"UP"}`.

## Reliability

- Input validation on `longUrl` (must be an absolute http(s) URL, max 2048 chars)
- Fixed-window rate limiting per client IP on the create endpoint
- Optional TTL-based expiration, enforced on every resolve
